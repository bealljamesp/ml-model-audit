# ml-model-audit

**Synthetic-data disclosure:** The synthetic parts of this project are generated, not observed. Every generated value comes from `src/ml_model_audit/synth.py` with a fixed seed, and the planted effects are recorded in `data/ground_truth.json`. Results on synthetic data depend on those planted assumptions. The Online Retail II data (planned, see Data sources) is real transactional data from a UK online retailer, not synthetic.

**Purpose:** A portfolio project showing that I understand the core concepts of applied ML: supervised and unsupervised learning, evaluation, explainability, time series, reproducibility, and some LLM and deep-learning work. It is a learning and demonstration project, not a production system. Where a result is weak or a method is only partly built, the status below says so.

**AI assistance:** The scaffold in the first commit was drafted with Claude's help. From the next commit on, I write the code myself, and Claude explains each step and reviews my work. I can explain every line that is committed here.

## Planned steps

1. Repo scaffold, README, tests run under pytest.
2. Obtain the UCI Online Retail II file and document its source.
3. Synthetic data generator with a fixed seed, planted effects, and a ground-truth file. Tests check that reruns match and that the planted effects are present.
4. Supervised learning with scikit-learn: linear and logistic regression, decision trees, random forests, gradient boosting, SVMs, k-nearest neighbors.
5. Evaluation: cross-validation, ROC/AUC, precision/recall, calibration, hyperparameter tuning. Report what the models recovered and what they missed against the ground truth.
6. Unsupervised learning: k-means, hierarchical and DBSCAN clustering, PCA, Isolation Forest.
7. Explainability with SHAP.
8. Time series forecasting with ARIMA, on the Online Retail II data.
9. LLM / RAG module: retrieval over a small local document set, with the LLM call behind an interface so tests use a fake model.
10. Small PyTorch model (recommended framework: PyTorch), compared against a scikit-learn baseline on the same split.
11. Docker image for reproducibility.
12. Kubernetes manifests (validated, not deployed to a cluster).
